# PicassoGallery - Android Art Gallery Application

PicassoGallery is an Android application that showcases Pablo Picasso's artwork, allowing users to explore paintings categorized by different periods in the artist's career.

## Features

- **Artwork Browsing**: View paintings organized by period (Blue Period, Rose Period, Cubism, etc.)
- **Detailed Information**: Access comprehensive details about each artwork.
- **Period Categories**:Filter paintings by artistic periods.
- **Complete Collection**: View all paintings in a single gallery.

## Technical Details

- **Platform**: Android
- **Languages**: Java
- **Architecture**: Activity-based navigation.
- **Storage**: SQLite database for artwork information.
- **UI Components**: RecyclerView for gallery displays.

## Requirements

- Android Studio
- Android SDK (minimum API level as specified in build.gradle)
- Java Development Kit (JDK)

## Installation

### Backend Setup

1. Clone this repository to your local machine:

    ```bash
    git clone https://github.com/aggsakellariou/AndroidGalleryApp.git
    ```

2. Open the project in Android Studio

3. Build and run the application on an Android emulator or physical device
